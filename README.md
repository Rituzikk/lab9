# **Лабораторная работа - Шифр Цезаря**

## Задание
Шифрование и расшифровка текста шифром Цезаря. Пользователь вводит строку и шаг сдвига.

Требования к программе:
- выбор действия (шифрование или дешифрование) осуществляется через меню;
- заглавные символы заменяются заглавными;
- цифры, знаки препинания и все символы, отсутствующие в алфавите, остаются без изменения;
- шаг сдвига не должен быть больше размерности алфавита.

Входные данные: команда шифрования или дешифрования, исходная строка, размер сдвига.

Выходные данные: зашифрованная или расшифрованная строка.

Дополнительно: качественный диалог с пользователем и обработка ошибок ввода для минимизации отказов при неправильном вводе.

## Среда разработки

Язык программирования: Python 3.

Проект можно открыть в PyCharm.

Файл проекта, который нужно открывать: `caesar.py`.

## Инструкция по работе

### Запуск
Открыть файл `caesar.py` в PyCharm и запустить его (Shift+F10) или выполнить в терминале:
```
python caesar.py
```

### Как пользоваться
Программа работает в консоли и по очереди запрашивает:
1. Действие в меню: `1` - зашифровать, `2` - расшифровать, `0` - выход.
2. Строку для шифрования или расшифровки.
3. Шаг сдвига: целое число от 1 до 33 (в русском алфавите 33 буквы).

После вывода результата программа снова показывает меню, чтобы можно было выполнить следующее действие. Для завершения работы нужно ввести `0`.

Русские буквы сдвигаются по алфавиту с сохранением регистра (заглавные остаются заглавными). Цифры, знаки препинания, пробелы и символы вне русского алфавита (например, латиница) остаются без изменений.

При неверном вводе (неверный пункт меню, пустая строка, шаг не число или вне диапазона 1-33) программа выводит сообщение об ошибке и повторяет запрос.

## Тесты

Тесты выполнены для своих ФИО со сдвигом, равным номеру в списке группы (7).

### Тест 1 - шифрование ФИО
Ввод: `1`, `Гуськова Маргарита Евгеньевна`, `7`.

### Тест 3 - надёжность (ошибки ввода и особые символы)
Ошибочный ввод: неверный пункт меню (`5`, `abc`), пустая строка, шаг `abc`, `0`, `34`, `-5`. Программа сообщает об ошибках и повторно запрашивает ввод, не завершаясь аварийно.

После ввода верного шага `7` строка `Привет, Мир! Hello 2026` шифруется в `Цчпилщ, Упч! Hello 2026`: регистр сохранён, а запятая, восклицательный знак, латиница и цифры не изменились.
